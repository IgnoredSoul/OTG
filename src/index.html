How to Install Your Theme in OBS Studio

1

Download Your .ovt Theme File

Click the green "Export Theme (.ovt)" button. The file will only contain the variables you changed from default Yami.

2

Place the File into Your OBS Themes Directory

Copy the downloaded .ovt file directly into your themes folder:

Windows Program Folder:
C:\Program Files\obs-studio\data\obs-studio\themes\
macOS (Not Tested):
~/Library/Application Support/obs-studio/themes/
Linux (Not Tested):
~/.config/obs-studio/themes/
3

Select the Theme in OBS Studio

Open or restart OBS Studio, navigate to Settings > Appearance > Style, select your new theme from the dropdown list, and click Apply!
